# ProcessX releases

Downloads for [ProcessX](https://github.com/bradbor23/ProcessX-releases/releases), a native macOS task manager.

- **Download:** the latest `.dmg` under [Releases](https://github.com/bradbor23/ProcessX-releases/releases).
- **Updates:** ProcessX checks `appcast.xml` (served by GitHub Pages) and installs updates signed with its update key.

Every build is signed with Developer ID and notarised by Apple. ProcessX sends nothing anywhere: the only request
it makes is the update check against this repository.

**Testing ProcessX?** The steps are in [TESTING.md](TESTING.md), and reports go in
[Issues](https://github.com/bradbor23/ProcessX-releases/issues).
