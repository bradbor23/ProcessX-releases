# TaskPilot releases

Downloads for [TaskPilot](https://github.com/bradbor23/TaskPilot-releases/releases), a native macOS task manager.

- **Download:** the latest `.dmg` under [Releases](https://github.com/bradbor23/TaskPilot-releases/releases).
- **Updates:** TaskPilot checks `appcast.xml` (served by GitHub Pages) and installs updates signed with its update key.

Every build is signed with Developer ID and notarised by Apple.
